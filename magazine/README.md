# Weekly Magazine PDFs

Drop each week's PDF issue in this folder, then add a matching entry to the
`magazineIssues` array in `index.html` (search for "WEEKLY MAGAZINE" in the
script section near the bottom of the file).

Example:
1. Add file: `magazine/2026-08-03-weekly-update.pdf`
2. Add to the array in index.html:
   {
     title: "Weekly Update — 28 Jul to 3 Aug 2026",
     date: "August 3, 2026",
     category: "GST",
     file: "magazine/2026-08-03-weekly-update.pdf"
   }

Categories used for the filter buttons: GST, Income Tax, FEMA, Accounting, Judgements.
